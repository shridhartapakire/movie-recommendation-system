# Movie Recommendation System

A content-based movie recommendation system built using Python and Natural Language Processing (NLP).

## Planned Features
- Movie data cleaning and preprocessing
- Text vectorization
- Cosine similarity-based recommendations
- FastAPI backend
- User interface for movie recommendations

## Learning Goals
- Understand recommendation systems
- Practice NLP and machine learning concepts
- Learn API development
- Practice Git and GitHub version control

Project setup in progress.
